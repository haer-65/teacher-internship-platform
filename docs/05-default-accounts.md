# 默认账号说明

当前项目在初始化数据后，会生成一组可直接用于演示和联调的默认账号。

## 1. 统一说明

- 默认初始密码：`123456`
- 登录账号以 `login_name` 为准，且已与学号/工号做过对齐
- 如果用户拥有多个角色，可以在登录后通过角色切换功能切换上下文

## 2. 默认账号清单

| 账号 | 角色 | 身份类型 | 说明 |
|---|---|---|---|
| `A0001` | 系统管理员 | ADMIN | 全局系统配置、用户和权限管理 |
| `D0001` | 院系管理员 | ADMIN | 院系侧计划、申请、分配和基础数据协同 |
| `J0001` | 教务管理员 | ADMIN | 教务侧计划统筹、成绩和业务监管 |
| `T0001` | 校内指导教师 | TEACHER | 过程材料评价和最终评价 |
| `B0001` | 基地指导教师 | TEACHER | 基地侧过程评价和综合评价 |
| `20230001` | 师范生甲 | STUDENT | 学生演示账号 |
| `20230002` | 师范生乙 | STUDENT | 学生演示账号 |

## 3. 演示时的推荐登录顺序

1. 先用 `A0001` 查看系统整体功能和基础数据。
2. 再用 `J0001` 或 `D0001` 走计划发布、申请审核和分配流程。
3. 用 `20230001` 或 `20230002` 走学生申请、材料提交和成绩查看流程。
4. 最后切到 `T0001` 或 `B0001` 展示评价与成绩计算流程。

## 4. 账号说明补充

- `A0001`、`D0001`、`J0001` 都是管理端角色，适合查看系统管理模块。
- `T0001` 和 `B0001` 适合演示过程评价、综合评价和评分。
- 学生账号适合演示计划浏览、申请、材料上传、通知查看和成绩查看。

## 5. 常见问题

### 5.1 登录后看不到某些菜单

通常是当前角色不具备对应菜单权限。可以切换到正确角色，或者检查 RBAC 配置。

### 5.2 密码不对

请确认使用的是初始密码 `123456`，并注意输入法和大小写。

### 5.3 账号无法找到

如果你是新建环境，请先完成数据库初始化，默认账号会在 bootstrap 种子数据中自动生成。
