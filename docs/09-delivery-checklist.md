# 交付检查清单

本文档用于项目交付前的最终检查，建议在发版、演示或提交前逐项确认。

## 1. 基础检查

- [ ] `README.md` 已更新为当前版本说明
- [ ] `docs/` 文档和实际功能一致
- [ ] 默认账号、默认密码和角色说明已确认
- [ ] 上传目录 `uploads/` 可写
- [ ] 本地依赖脚本可执行

## 2. 启动检查

- [ ] MySQL 可用，端口 `3306` 正常监听
- [ ] Redis 可用，端口 `6379` 正常监听
- [ ] 后端可启动，端口 `8080` 正常监听
- [ ] 前端可启动，端口 `5173` 正常监听
- [ ] 健康检查接口可访问：`/api/v1/health/check`

## 3. 功能检查

### 3.1 认证与系统

- [ ] 登录成功
- [ ] 角色切换可用
- [ ] 用户管理可用
- [ ] 角色权限配置可用
- [ ] 菜单和基础数据能正常展示
- [ ] 系统参数和日志可查看

### 3.2 主业务流程

- [ ] 实习计划可创建、编辑、发布和归档
- [ ] 学生可查看已发布计划
- [ ] 学生申请可提交、编辑和撤回
- [ ] 管理员可审核申请
- [ ] 管理员可完成人工或批量分配
- [ ] 学生可上传过程材料
- [ ] 教师可完成过程评价和综合评价
- [ ] 成绩可计算、调整、发布和导出

### 3.3 扩展能力

- [ ] 通知可发送、阅读和统计未读数
- [ ] 到期提醒可触发
- [ ] 统计分析页面可正常展示

## 4. 发布检查

- [ ] 后端 `mvn clean package -DskipTests` 成功
- [ ] 前端 `npm run build` 成功
- [ ] API 文档页面可访问
- [ ] 浏览器端关键页面无空白或报错
- [ ] 演示账号可以完整走通主流程

## 5. 演示前检查顺序

1. 先验证数据库和 Redis。
2. 再验证登录和菜单权限。
3. 然后走计划、申请、分配、材料、评价、成绩、通知流程。
4. 最后打开统计页面做收尾。

## 6. 常见遗漏项

- [ ] 默认密码不是旧密码
- [ ] 计划没有发布导致学生端看不到
- [ ] 角色权限没有重新绑定
- [ ] 文件上传目录路径不一致
- [ ] 后端启动时 bootstrap 被关闭
