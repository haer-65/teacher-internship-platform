# 演示流程文档（课程答辩版）

## 1. 演示目标

在 10-15 分钟内完成“计划发布 -> 学生申请 -> 分配落实 -> 材料提交 -> 指导评价 -> 成绩发布 -> 消息/统计”的核心闭环演示。

## 2. 演示账号

1. 院系管理员：`D0001 / 123456`
2. 师范生：`20230001 / 123456`
3. 校内指导教师：`T0001 / 123456`
4. 基地指导教师：`B0001 / 123456`
5. 系统管理员（可选）：`A0001 / 123456`

## 3. 演示前准备

1. 后端、前端、MySQL、Redis 全部启动。
2. 已执行 `sql/V1` 到 `sql/V13`。
3. `uploads` 目录存在且有写权限。
4. 准备演示文件（建议：`pdf`、`docx`、`jpg` 各 1 份）。

## 4. 演示主流程

### 步骤 1：院系管理员创建并发布计划

1. 使用 `D0001` 登录。
2. 进入“实习计划”创建草稿，建议将报名截止设置为未来时间（例如 `2026-06-30 23:59:59`）。
3. 配置材料类型与权重、双导师权重，确认权重和为 100。
4. 发布计划。
5. 观察点：发布成功后触发站内消息（计划发布通知）。

### 步骤 2：学生提交申请

1. 退出并登录 `20230001`。
2. 进入“申请分配”，选择刚发布计划提交申请。
3. 可演示“修改申请”或“撤回后再提交”。
4. 观察点：同一学生同一计划仅允许一条有效申请。

### 步骤 3：院系管理员审核并分配

1. 登录 `D0001`，在“申请分配”审核学生申请。
2. 执行手动分配：指定实习基地、校内指导教师、基地指导教师。
3. 如需演示变更，执行一次“分配调整”并填写原因。
4. 观察点：分配历史可追溯，系统保留版本记录。

### 步骤 4：学生上传材料并产生版本

1. 登录 `20230001`，进入“过程材料”上传材料。
2. 对同一材料类型再次上传，触发版本递增。
3. 查看版本历史并演示预览/下载。
4. 观察点：系统校验格式、大小（<=20MB）与截止时间。

### 步骤 5：教师过程评价与综合评价

1. 登录 `T0001`（可再切 `B0001`）进入“指导评价”。
2. 对某个材料版本提交过程评价（分项评分 + 评语）。
3. 提交综合评价（综合分 + 意见）。
4. 观察点：评价与材料版本绑定，且保留历史记录。

### 步骤 6：成绩计算、复核与发布

1. 登录 `D0001` 进入“成绩管理”。
2. 执行重算，查看成绩明细。
3. 演示人工调整一次并填写原因。
4. 发布成绩。
5. 观察点：发布前预览、发布后学生可见、调整写入审计日志。

### 步骤 7：学生查看结果与消息

1. 登录 `20230001` 查看“成绩单”和“消息中心”。
2. 演示消息已读/未读变化与未读角标刷新。

### 步骤 8：统计分析（可选收尾）

1. 登录 `D0001` 或 `J0001` 进入“统计分析”。
2. 按计划和院系筛选，展示图表与表格双视图。
3. 导出当前筛选结果。

## 5. 关键讲解点（答辩建议）

1. 权限控制：前端守卫 + 后端鉴权双保险，最终以后端为准。
2. 可追溯能力：申请、分配、材料版本、评价、成绩调整、日志全链路留痕。
3. 安全性：文件不暴露物理路径，统一经后端鉴权访问。
4. 可运维性：SQL 脚本版本化，文档与部署流程可复现。
