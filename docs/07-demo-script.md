# 演示脚本

本文档给出一套适合答辩、汇报和演示的视频/现场讲解脚本。整体建议控制在 10 到 15 分钟。

## 1. 开场介绍

可以先用 20 到 30 秒说明：

- 平台名称
- 面向的业务场景
- 覆盖的角色
- 主业务闭环

示例话术：

> 这个平台用于管理师范生教育实习全过程，覆盖计划发布、学生申请、指导教师分配、材料提交、评价打分、成绩发布和统计分析，支持院系、教务、教师和学生多角色协同。

## 2. 演示顺序

### 2.1 登录与首页

账号：`A0001`

展示内容：
- 登录
- 首页工作台
- 未读消息
- 系统总览

讲解重点：
- 说明平台采用统一权限控制
- 说明不同角色登录后菜单不同

### 2.2 基础数据与系统配置

账号：`A0001`

展示内容：
- 院系、专业、年级、实习基地
- 系统参数
- 用户管理
- 角色权限
- 菜单配置
- 登录和操作日志

讲解重点：
- 基础数据是计划和申请的前置条件
- RBAC 保证不同角色只看见对应功能

### 2.3 实习计划发布

账号：`J0001` 或 `D0001`

展示内容：
- 创建计划草稿
- 编辑计划信息
- 上传附件
- 配置材料类型
- 发布计划
- 学生端查看已发布计划

讲解重点：
- 计划发布后才进入学生申请阶段
- 附件和材料类型决定后续提交要求

### 2.4 学生申请与分配

账号：`20230001`

展示内容：
- 查看可申请计划
- 填写申请
- 提交申请
- 查看申请状态和详情

再切回管理员账号展示：
- 审核申请
- 手动分配
- 批量导入分配
- 调整分配结果

讲解重点：
- 申请和分配是实习主流程的核心转折点
- 分配结果会影响材料、评价和成绩

### 2.5 过程材料

账号：`20230001`

展示内容：
- 进入我的材料
- 上传材料
- 查看版本历史
- 查看材料状态

再切换到教师或管理员账号：
- 查看学生材料列表
- 查看文件预览
- 控制是否允许重提

讲解重点：
- 材料支持版本追踪
- 系统支持过程留痕，便于后续追责和回溯

### 2.6 评价

账号：`T0001` 或 `B0001`

展示内容：
- 过程评价待办
- 过程评价详情
- 提交评价
- 综合评价详情
- 提交综合评价

账号切回学生：
- 查看评价结果

讲解重点：
- 评价分为过程评价和综合评价
- 学生能够回看最终结果

### 2.7 成绩

账号：`J0001` 或 `A0001`

展示内容：
- 成绩列表
- 成绩详情
- 重算成绩
- 调整成绩
- 发布成绩
- 导出成绩单

账号切回学生：
- 查看个人成绩单

讲解重点：
- 成绩来源于计划权重、评价记录和材料结果
- 结果可以人工调整并保留痕迹

### 2.8 通知与统计

账号：`A0001` 或 `D0001`

展示内容：
- 通知列表
- 未读数
- 详情阅读
- 手动发送通知
- 触发到期提醒
- 统计分析页面

讲解重点：
- 通知用于串联关键节点
- 统计模块用于过程汇总和结果分析

## 3. 收尾总结

可以用 20 到 30 秒收口：

> 平台已经完成从计划到成绩的闭环管理，既支持日常业务操作，也支持过程留痕、权限控制和统计分析，能够满足师范生教育实习管理的核心需求。
